# DNS Manager

Windows-приложение для управления DNS-серверами сетевых адаптеров: быстрое
переключение между профилями DNS (GeoHide, Cloudflare, AdGuard и др.),
фоновый мониторинг здоровья DNS с автовосстановлением и реакция на изменение
DNS сторонними программами.

Стек: **Python + tkinter + pystray + PyInstaller**. Только Windows
(используются `netsh`, `PowerShell`, `schtasks`, реестр и Win32 API).

## Возможности

- **Профили DNS-кнопок** — преднастроенный набор (GeoHide, Cloudflare,
  AdGuard, Xbox-dns, Comss и др.), редактируемый через интерфейс. Можно
  добавлять свои, в том числе полуавтоматически — «получить DNS по ссылке»
  (приложение пытается определить адреса по A-записи домена или по тексту
  страницы; ничего не выдумывает — при неудаче просит ввести вручную).
- **GeoHide** — служебный профиль с динамическим резолвом `dns.geohide.ru`
  (IP обновляются автоматически, есть захардкоженные резервы).
- **Мониторинг здоровья DNS** — периодическая проверка, что выбранный режим
  фактически активен и DNS отвечает. При сбое — автоматическое
  восстановление (сброс на DHCP, ожидание интернета, повторное применение).
- **Реакция на внешнее изменение DNS** — уведомление пользователя или
  автоматический возврат выбранного режима.
- **Умная привязка к адаптеру** — выбор активного адаптера по default-маршруту,
  авто-перепривязка при пропаже сети (с проверкой реального интернета через
  NCSI, чтобы не перепривязываться на captive portal), возврат к явному
  выбору пользователя, когда тот снова доступен.
- **Автозапуск** — обычный (HKCU\Run) или с правами администратора
  (Планировщик заданий, без UAC-промпта при логине).
- **Трей** — работа в фоне, меню быстрого переключения.

## Запуск из исходников

Требуется Python 3.8+ для Windows.

```bat
python -m venv .venv-build
.venv-build\Scripts\python -m pip install -r requirements.txt
.venv-build\Scripts\python dns_manager.py
```

Аргументы командной строки:

- `--minimized` — запуск сразу в трей (используется автозапуском Windows).

## Сборка exe

```bat
python -m PyInstaller --onefile --noconsole --name DNSManager ^
    --version-file version.txt --hidden-import dnsmgr ^
    --collect-submodules dnsmgr dns_manager.py
```

Результат — `dist\DNSManager.exe`. Имя `DNSManager.exe` и точка входа
`dns_manager.py` — фиксированные: на них ссылаются записи автозапуска в
реестре и Планировщике.

## Структура проекта

Логика разбита на пакет `dnsmgr/` с однонаправленным графом зависимостей.
Корневой `dns_manager.py` — тонкая точка входа.

```
dns_manager.py          Точка входа (импортирует dnsmgr.main)
dnsmgr/
  constants.py          Все константы, пути, тайминги, профили по умолчанию
  logger.py             AppLogger (файл + GUI), синглтон app_logger
  config.py             settings.json, валидация DNS-профилей
  process.py            права администратора (UAC), single-instance мьютекс
  network.py            адаптеры, чтение/применение DNS, проверки сети, NCSI
  geohide.py            резолв dns.geohide.ru, «получить DNS по ссылке»
  monitor.py            HealthMonitor + NetworkChangeWatcher
  autostart.py          реестр Run, Планировщик заданий, очистка старых записей
  app.py                DNSManagerApp — GUI, трей, диалоги, оркестрация
  main.py               main(): single-instance, очистка, запуск GUI
tests/                  Юнит-тесты чистых функций (unittest)
version.txt             VSVersionInfo для PyInstaller
```

Граф зависимостей модулей:

```
constants → logger → config → process → network → geohide → monitor → app → main
                                       autostart ──┘
```

## Тесты

Юнит-тесты покрывают чистые функции (валидация профилей, распознавание
режима DNS, проверка публичных IPv4, разбор ссылок, парсинг команд
автозапуска). Зависимостей сверх стандартной библиотеки не требуют.

```bat
python -m unittest discover -s tests -v
```

## Где хранятся данные

- Настройки: `%APPDATA%\DNSManager\settings.json`
- Лог: `%APPDATA%\DNSManager\dns_manager.log` (автообрезка до 10000 строк)

## Права администратора

Изменение DNS (`netsh`), мониторинг и автовосстановление требуют прав
администратора. Без них приложение работает в режиме «только чтение» и
предлагает перезапуск с повышением прав.
